Soccer Planner API

JWT-protected REST endpoints for mobile clients. Send the token in Authorization: Bearer <jwt>.

POST/api/auth/login

Body: {"email":"user@example.com","password":"secret"}

Returns: {"token":"...","user":{...}}

GET/api/matches?page=1&pageSize=10

Lists active matches that are still open for joining. Requires JWT auth.

GET/api/matches/[id]

Returns match details, joined players, and comments.

POST/api/matches/[id]/join

Joins the current user to the match if there is room.

POST/api/matches/[id]/leave

Removes the current user from the match.

POST/api/matches/[id]/slots

Body: {"extraSlots": 0} or a larger integer to reserve additional slots.
