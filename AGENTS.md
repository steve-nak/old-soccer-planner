# Soccer Planner Software System
We are building a full-stack software system "Soccer Planner":
  - Back-end: TypeScript + Next.js + Drizzle ORM + PostgreSQL
  - Web front-end: TypeScript + Next.js + React + Tailwind
  - Mobile app: React Native + Expo (connects to the back-end API)

# Folder Structure
Monorepo, holding two workspaces:
  - `soccer-web/`: Next.js app (RESTful API + Next.js Web app)
  - `soccer-mobile/`: Expo mobile app (connects to the Next.js backend)
